\*\*¿Qué es un programa informático?\*\*



Un programa informático es un conjunto de instrucciones hechas con un lenguaje de programación que le indican al ordenador las acciones a seguir para llevar a cabo un objetivo determinado.







\## Diferencia entre código fuente, código objeto y código ejecutable.



* Código Fuente: Son un conjunto de instrucciones que escribe un programador en un lenguaje de programación como puede ser Java.



* Código Objeto: Es la traducción del código fuente por un compilador, no esta pensado para ser leído por un humano directamente y usa unas instrucciones mas cercanas al lenguaje maquina.



* Código Ejecutable: Es el conjunto de archivos que contiene las instrucciones para que el sistema pueda ejecutarlas.







\*\*Etapas del desarrollo del software.\*\*



1. \*\*Análisis de requisitos: \*\*

Se identifica lo que necesita el usuario y las funciones que debe tener el programa.



2\. \*\*Diseño:\*\*

Se planifica como estructurar el software y como funcionaran sus componentes.



3\. \*\*Implementación:\*\*

Se escribe el código fuente del programa.



4\. \*\*Pruebas:\*\*

Se comprueba el funcionamiento del programa y se buscan errores.



5\. \*\*Despliegue:\*\*

Es el momento donde el software se lanza o se da acceso a los usuarios.



6\. \*\*Mantenimiento:\*\*

Se realizan mejoras, incorporación de nuevas funcionalidad y corrección de errores.
